# 14 — User Manual

Audience: University staff, students, the core content team, and members of the public using UBIRR.

## 1. Public visitors

### Browsing the library
1. Visit the homepage at `biosafety.unza.zm` (or the deployed URL).
2. Use the search bar to find resources by keyword.
3. Click any tile to open the resource detail page.
4. If the resource is downloadable, click **Download** — a secure link opens in a new tab.

### Viewing events
The Events page lists upcoming University events open to the public.

## 2. Authenticated University users (staff/students)

### Signing in
1. Click **Sign in** in the top-right.
2. Enter your University email and password.
3. New accounts default to the **Student** role; administrators can elevate.

### Accessing restricted resources
After signing in, the library automatically reveals resources scoped to your role (university, staff, or student). No extra action required.

## 3. Content contributors

### Creating content
1. Sign in. Click **Admin** (only visible if you hold a content role).
2. Open **Content → New content**.
3. Fill in title, summary, type, and access level. Set access to `draft` while editing.
4. Save. After saving, the **Files** panel appears — upload as many files as needed.
5. When ready, click **Submit for review**.

### Responding to review
If a reviewer returns your item, open it from **Content**, address the comments, and submit again.

## 4. Reviewers

### Working the approval queue
1. Open **Approvals**.
2. For each item: **Approve**, **Return** (with comments), or **Reject** (with reason).
3. Approved items move to a Project Administrator for publication.

## 5. Project administrators

### Publishing
After approval, open the item under **Content** and click **Publish**. Published items become visible according to their access level.

### Archiving
Open the item and click **Archive** to remove it from public listings while keeping its history.

## 6. Digitization officers

### Recording a hard-copy item
1. Open **Digitization → New record**.
2. Capture source title, owner, physical location, and page count.
3. Save with status `pending`.
4. After scanning, attach the file and add OCR text, then move the status forward.

## 7. Accounts & passwords

- Forgot your password: use the **Forgot password** link on the sign-in page.
- Change role: ask an administrator; roles can only be changed by `project_admin` or `super_admin`.
- Sign out: click **Sign out** in the header or in the admin sidebar.

## 8. Getting help
Email **biosafety@unza.zm** or contact the project administrator.
