# 06 - Security Plan

## Core controls

- Spring Security protects authenticated routes.
- JWT bearer tokens are validated by `JwtAuthenticationFilter`.
- Passwords are hashed with `BCryptPasswordEncoder`.
- Role checks are enforced in service methods through `AuthContextService`.

## Access model

- Public endpoints stay under `/api/public/**`.
- Account endpoints require a valid authenticated user.
- Admin endpoints require content-manager or administrator roles depending on the operation.
- File preview and download access is checked against the owning `ContentItem`.

## Password handling

- Registration stores only hashed passwords.
- Password changes go through authenticated endpoints.
- Password reset tokens are generated by the backend and validated on reset.

## File security

- Uploaded files are stored outside the browser and served only through backend endpoints.
- Preview and download requests are checked before the file stream is returned.
- Audit and download/view tracking are stored in the database.

## Operational guidance

- Replace `app.jwt.secret` before production use.
- Restrict `app.cors.allowed-origin-patterns` in production.
- Move from H2 to PostgreSQL or another managed relational database for production workloads.
- Store the `app.storage.root` path on persistent storage.
